# 项目简介

## 核心功能
- 基于YOLOv8的数字字母检测系统，支持识别36类字符（0-9，A-Z）
- 提供完整源码、900张标注数据集、训练好的模型及训练结果
- 支持多种输入方式：单张图片、图片文件夹、视频文件、本地摄像头
- 提供图形用户界面，实时显示目标位置、目标总数和置信度信息
- 支持自定义检测参数：置信度阈值、IOU阈值
- 提供多种显示选项：标签显示、原图显示
- 支持批量检测功能，可查看所有检测结果
- 提供检测结果保存功能
- 包含完整项目运行教程和使用文档

## 适用场景
- 字符识别应用开发
- 数字字母分类研究
- 计算机视觉教学实验
- 自动化检测系统原型设计
- 图像处理项目开发

## 技术特点
- 采用Pycharm+Anaconda或VSCode+Anaconda开发环境
- 基于Python 3.9实现，依赖opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 提供完整UI界面源文件和图标资源
- 模型已训练完成，配置成功环境可直接使用
